# Knowledge Database

Version: 1.0

## Purpose

The Knowledge Database is the centralized information repository for the AI Influencer Operating System.

It provides structured knowledge to all AI Agents, Workflows, and the Runtime.

The database contains information about:

- Travel
- Photography
- Fashion
- Social Media
- Marketing
- Psychology
- Branding
- Business
- Platform Guidelines

All agents should retrieve knowledge from this module instead of embedding static knowledge into prompts.

Status: Active
