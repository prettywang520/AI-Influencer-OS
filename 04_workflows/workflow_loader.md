# Workflow Loader

Version: 1.0

---

Purpose

Load workflow configuration before execution.

Load Sequence

1. Load Workflow Definition

2. Load Context

3. Load Persona

4. Load Brand

5. Load Memory

6. Load Required Agents

7. Validate Workflow

8. Send to Runtime

---

Validation Rules

Workflow exists

Workflow version is valid

Required agents exist

Required memory exists

Required database exists
