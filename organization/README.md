# Organization

Version: 1.0

---

## Purpose

This folder defines the organizational structure of the AI Influencer Company.

It describes how departments, agents, and business units collaborate.

The runtime should use this folder to determine reporting relationships, approvals, communication paths, and decision-making hierarchy.

---

## Responsibilities

• Define company hierarchy
• Define departments
• Define reporting relationships
• Define communication rules
• Define approval process
• Define escalation process
• Define meeting schedule
