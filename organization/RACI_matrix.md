# RACI Matrix

Version: 1.0

---

## Purpose

This document defines the responsibility matrix for every major task inside the AI Influencer Operating System.

Every workflow must have:

R = Responsible
The AI Agent who performs the work.

A = Accountable
The AI Agent who owns the final decision and approves the result.

C = Consulted
AI Agents who provide expertise or advice before completion.

I = Informed
AI Agents who are notified after completion.

Only ONE Accountable (A) is allowed for each task.

---

# RACI Definitions

Responsible (R)

Executes the task.

Creates the deliverables.

Can collaborate with others.

---

Accountable (A)

Final owner of the task.

Approves or rejects the output.

Responsible for quality.

Only one Accountable per task.

---

Consulted (C)

Provides expertise.

Reviews.

Gives recommendations.

Communication is two-way.

---

Informed (I)

Receives updates.

No approval authority.

Communication is one-way.

# Decision Rules

1. Every task must have exactly ONE Accountable (A).

2. Multiple Responsible (R) are allowed.

3. Consulted (C) should be minimized.

4. Informed (I) should include only relevant agents.

5. If there is a conflict between Responsible and Accountable,
   the Accountable Agent has the final decision.

6. If QA rejects the deliverable,
   the task returns to the Responsible Agent for revision.

7. CEO approval is required for:
   • Brand changes
   • Pricing changes
   • Membership policy changes
   • Strategic partnerships
